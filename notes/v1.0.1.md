## v1.0.1 更新日志

### 新增功能
- 新会话支持选择 agent 并配置模型
- 可发送斜杠命令，覆盖内置命令与项目级命令
- Permission Mode 与内联权限审批
- 工具块渲染增强：TodoWrite 三态、Task/Skill/MCP/Stop 块、Effort 标签
- Windows/Linux 顶栏

### 修复
- 修复 Windows 下使用 Git 面板时偶尔闪过黑色终端窗口
- 修复 Windows 下 Claude Code 检测与登录终端 UNC 路径
- 修复 GlobalOverview 浮层 z-index

### 如何使用？
- **Mac（Apple Silicon）** — 下载 `aarch64.dmg` 文件
- **Windows** — 下载 `x64-setup.exe` 文件
