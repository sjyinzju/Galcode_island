# TODO：UX 优化方向（剩余项）

来源：2026-05-11 会话里的 14 项优化建议清单。本批确认要做 6 件（见 `docs/handoff/ux-batch/PROGRESS.md`），剩下 8 件按 Tier 暂存在这里。

## Tier 1：立即见效（每条 0.5-1 天）

### 命令面板 Cmd+K
聚合"切 tab / 打开设置 / 跳历史 / 触发任意操作"的浮窗 + fuzzy match。
**为什么**：所有功能键盘直达，未来加新功能不用挤主界面。
**做法**：浮窗组件 + 操作注册表 + cmd+K 全局快捷键。

### 完整快捷键体系
Cmd+T 新 tab、Cmd+W 关、Cmd+1..9 跳第 N tab、Cmd+/ 切相邻 tab。
**为什么**：把"多 tab 并行"核心卖点推到极致。
**做法**：useGlobalHotkeys hook，调度到 tabsStore action。

## Tier 2：差异化价值（每条 2-3 天）

### 多 tab 任务面板（鸟瞰图）
新视图：每个 tab 一卡片，显示状态 / 已用时间 / 最新输出 / 进度条。
**为什么**：3-5 个 agent 同时跑时，TabBar 信息密度不够。
**做法**：新增 `OverviewDashboard.tsx`，从 tabsStore 聚合状态。

### 桌宠"过程叙事"
流式 block 经过时让桌宠每 N 步发一句风格化短评（凉宫春日风），从"装饰"做成"陪跑伙伴"。
**为什么**：核心差异化（桌宠氛围）从静态图升级为有生命的反馈。
**做法**：流监听 hook + 节流 + LLM 生成短评 + emotion bubble 复用。

## Tier 3：长期沉淀

### 首次 onboarding + 内置 demo 项目
5 步 tour（tab/输入/桌宠/设置/历史）+ 不需要选目录就能玩的示例项目。
**为什么**：降低首次使用门槛，避免新用户被"必须选目录 + 装 CLI"劝退。

### 拖放支持
- 拖目录入主窗口 → 自动新建 tab 选这个目录
- 拖文件入输入气泡 → 路径作为 context 拼进 prompt
**为什么**：贴近开发者直觉的快捷输入。

### 明暗色一致性审计
扫一遍新加的组件（特别是 `GitDiffViewer` 浅色下仍是黑底）。
**为什么**：UI 一致性影响整体专业感。

### 手机端手势 / 触摸目标
滑动切 tab、长按 block 弹菜单、触摸目标尺寸 ≥44px。
**为什么**：局域网手机访问已是产品特色，但目前是同一份桌面 React 直接搬，未做手势/触摸适配。
