## v1.0.0 正式版发布

Galcode Island - 一款二次元风格化的 Agent 工作台。

我们以二次元风格化为出发点，为此工作台开发了诸多实用功能，以兼顾对于美化、角色扮演、实用性的不同程度的需要。

目前版本仅可使用预设的一套凉宫春日风格，后续我们将开发社区功能，让大家可以上传或下载自己喜欢的角色。

### 实用功能特性
- 在工作台中使用 Codex / Claude Code / OpenCode。
- 通过侧边栏妥善管理多任务与历史会话。
- 在工作台中使用 Git 的主要功能，创建提交、切换分支、查看提交记录、查看代码 diff等。
- 创建局域网可访问的链接，通过其它设备管理主机上的项目，受密码保护。也可自行将其转发为公网可访问的链接。（注意安全！）
- 可选择将输入自动翻译为英文、将模型输出自动翻译为中文。

### 风格化功能特性
- 在不同工作阶段，显示对应的动画表情作为反馈，并可自定义这些表情。
- 每轮任务完成后，进行角色扮演风格的总结，并提供多个后续操作建议。该功能独立于agent流程，不影响模型表现。

### 如何使用？
- **Mac（Apple Silicon）** — 下载 `aarch64.dmg` 文件
- **Windows** — 下载 `x64-setup.exe` 文件
