## v1.1.0 更新日志

此版本主要更新了个性化系统，允许用户配置自己的桌宠表情与人设，并从社区中下载他人制作的预设。

### 新增功能

#### 桌宠预设系统
- 新增「个性化」入口，可以在其中修改桌宠动态表情，并配置人设。
- 用户可以在社区中下载他人制作的预设，也可以上传自己的预设。预设是一套动态表情与人设的集合。
- 用户也可以在社区中查看他人上传的单张表情，并独立应用到自己制作的预设中。
- 可以配置预设级人设，也可以为每张表情配置独立的人设。

### 修复
- Windows 下 Git 操作不再偶发闪过黑色终端窗口

### 如何使用？
- **Mac（Apple Silicon）** — 下载 `aarch64.dmg` 文件
- **Windows** — 下载 `x64-setup.exe` 文件
